RadioHY Addon for Kodi
======================
version 5.0.0

### Summary ###
This is a plugin for [Kodi](https://kodi.tv) that enables you to listen to Armenian radio stations broadcasting online. It includes 55 active streams from Armenia, USA, Lebanon, France, and other countries.

### Setup/Installation ###
Install the zip package through Kodi's Add-on browser: *Add-ons → Install from zip file*.
